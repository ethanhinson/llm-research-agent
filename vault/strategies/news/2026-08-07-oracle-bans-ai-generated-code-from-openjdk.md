# Oracle bans AI-generated code from OpenJDK

## Summary
Oracle has banned AI-generated code from OpenJDK contributions, citing safety, security, and intellectual property concerns. The policy allows developers to use LLMs privately for debugging and review but prohibits submission of AI-generated material to repositories or pull requests.

## How It Works
Developers may use LLMs as private tools for debugging and code review but cannot contribute AI-generated code to OpenJDK repositories, pull requests, or project channels. The restriction applies to all submissions to the open-source Java project.

## Why It Matters
The ban creates friction between Oracle's public stewardship of OpenJDK and its stated internal reliance on AI code generation—co-founder Ellison recently claimed AI now writes Oracle's code, and co-CEO Sicilia credited AI tools with productivity gains. For practitioners, this signals that major open-source custodians are drawing hard lines on AI-generated contributions despite corporate adoption of LLMs internally, which may influence contribution policies across other projects and raise questions about governance consistency.
