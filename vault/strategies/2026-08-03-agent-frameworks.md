# Agent frameworks

## Summary
An AI agent framework provides reusable abstractions for building and operating goal-directed systems that use models, tools, state, and control logic.

## How It Works
An AI agent framework provides reusable abstractions for building and operating goal-directed systems that use models, tools, state, and control logic. Depending on the product, those abstractions may include agent loops, tool registration, handoffs, graph execution, session state, durable checkpoints, memory, human approval, deployment, tracing, and evaluation.
