# mem0ai/mem0

## Summary
Mem0 is an intelligent memory layer for AI assistants and agents that stores and retrieves user context across sessions. A new token-efficient memory algorithm achieves large benchmark gains—92.5 on LoCoMo (+21 points), 94.4 on LongMemEval (+27 points)—while keeping token usage around 6.7–7.0K per retrieval.

## How It Works
The updated algorithm uses single-pass ADD-only extraction (one LLM call, no UPDATE/DELETE operations), entity linking across memories, and multi-signal retrieval that fuses semantic matching, BM25 keyword search, and entity matching. Temporal reasoning ranks the correct dated memory instance for queries about current state, past events, and upcoming plans. The system supports three deployment modes: library (testing), self-hosted server (team infrastructure), and cloud platform (zero-ops production).

## Why It Matters
Practitioners building conversational AI, customer support agents, or multi-turn autonomous systems benefit from dramatic retrieval accuracy improvements without proportional token overhead—enabling personalized, context-aware interactions at production scale. The framework is open-sourced for reproducibility, and Mem0 provides fast onboarding (four commands to set up) and integrations with popular frameworks (Langgraph, CrewAI), making it practical to add persistent memory to existing agent pipelines.
