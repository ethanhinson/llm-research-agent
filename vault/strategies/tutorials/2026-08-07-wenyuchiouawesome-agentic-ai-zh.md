# WenyuChiou/awesome-agentic-ai-zh

## Summary
A comprehensive Chinese-language learning roadmap and curated resource hub for transitioning from LLM user to agentic AI system builder. It structures progression through 8 stages with two parallel learning tracks (CLI Power User vs. Agent Builder), supplemented by 240+ curated projects, 77 MCP/Skill references, and 23 hands-on coding exercises.

## How It Works
The curriculum spans foundational concepts (Python, tokens, prompts) through advanced topics (multi-agent orchestration, Computer Use, context engineering). Two entry points diverge after Stage 2: Track A focuses on using existing CLI agents in production workflows (8–10 weeks); Track B covers building custom agents from scratch using frameworks like LangGraph and AutoGen (16–22 weeks). Two shared "hub" stages (Stage 5 on Claude Code ecosystem, Stage 8 on agent interfaces) serve both tracks with different depth levels. Each stage includes 1–5 illustrative exercises (70–150 lines, with dual SDK paths: Anthropic/Ollama) and curated external resources ranked by relevance and difficulty.

## Why It Matters
Practitioners benefit from a single structured onramp that bridges conceptual understanding and hands-on implementation, reducing the cognitive load of learning a rapidly evolving domain. The explicit separation of use-case tracks (CLI power user vs. builder) and persona-based extensions (researcher, developer, teacher, knowledge worker) allow learners to skip unnecessary material and focus on their immediate needs. The emphasis on doing code exercises rather than passive reading, combined with real-world recipe examples and glossary support for domain terminology, makes it directly applicable to shipping agentic systems in 2024–2026 workflows.
